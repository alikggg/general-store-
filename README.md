# Green Basket Store
A responsive general-store e-commerce starter built with React, Vite and Supabase.

Features:
- Responsive product catalogue, search, categories and sorting
- Cart, delivery fee calculation and checkout
- Cash on delivery and bank-transfer reference entry
- Supabase-backed product management, order list and status updates
- Store branding/contact controls, announcement bar and live store-wide sale switch
- Product-specific old price field for sale display

See [SETUP.md](./SETUP.md) for full setup, deployment and safety notes.
